# NicheLink - A Community Platform for Remote Workers

NicheLink is a full-stack MERN platform designed to connect remote workers in specific industries through persistent micro-communities, real-time messaging, and tiered subscription features[span_2](start_span)[span_2](end_span).

## 🚀 Tech Stack
* **Frontend:** React.js, React Router, Axios, Socket.io-client[span_3](start_span)[span_3](end_span)
* **Backend:** Node.js, Express.js, Socket.io, JWT, Bcrypt[span_4](start_span)[span_4](end_span)
* **Database:** MongoDB (Mongoose)[span_5](start_span)[span_5](end_span)
* **Monetization:** Stripe API[span_6](start_span)[span_6](end_span)
